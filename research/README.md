# Research Artifacts

This folder contains non-runtime project material related to the dashboard's academic and reporting work.

## Included Here

- `paper_draft.html`: working HTML paper draft
- `screenshots/`: dashboard screenshots used by the paper draft

## Local Or Generated Artifacts

PDF exports and interview notes may exist here as local working files. They are not required to run the dashboard application.

## Rule

If a file is only needed for reporting, screenshots, or paper-writing, keep it here rather than in the repository root.
